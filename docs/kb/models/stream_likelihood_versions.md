# Stream likelihood versions

Every stream ln L quoted in the journal, the plots or the paper was computed with one of the score versions below. Numbers from
different versions are **not comparable**. The [stream results index](stream_results_index.md) assigns each saved result file
to a version, the script that wrote it, its non-default score options, its spray settings (particle number, seeds, frame,
host options) and the code commit (generated by `bin/streams/score_provenance.py` from `bin/streams/score_registry.py`, a code
audit of all 51 scripts that call a stream score, 2026-10-17).

From 2026-10-17 every call to `grid4_common.score()` returns `settings` (version tag, explicit options, code commit, `-dirty`
if the score code had uncommitted changes); scripts that save scores should store it with their results.

## Versions

| tag | from commit (date) | function | what changed |
|---|---|---|---|
| S0 | `89b1473` (2026-10-09 01:24) | `score` | per-star sky-conditional score |
| S1 | `7183e33` (2026-10-09 06:20) | `score_chi_kde` | chi-binned KDE with latent chi; capped bandwidths from `b5598ca` |
| S2 | `29d04f8` (2026-10-09 14:01) | `score_conditional` | conditional p(w \| u) chi-KDE; equal-weight chi bins; background widths implied |
| S3 | `ff312ad` (2026-10-17 06:51) | `score_conditional` | as S2, uniform background normalised over an explicit box containing every member |
| S4-pooled | the commit that made `pooled=True` the default (2026-10-17) | `score_conditional` | as S3, one KDE of all debris (no chi bins) |

Results from before S0 (until 2026-10-09 01:24) did not use a per-star likelihood (track comparisons, validation checks).

## Settings common to S2-S4

Fixed since `29d04f8` (checked against the function signature at every later commit that touched the score):

- kernels: h_u = h_x = 0.5 deg (along / across the stream in the chord great-circle frame), PMs 0.2 mas/yr added to each
  member's Gaia covariance, v_los 5 km/s added to the measurement error;
- background fraction eps = 0.05; release-age cut 700 Myr; trailing-arm particles with chi > 0;
- chi bins (S2, S3 only): width 5, minimum 20 particles, each kept bin weight 1/K;
- background: S2 widths 12 deg (Delta phi2) x 30 x 30 mas/yr x 400 km/s; S3 onwards the box `BG_BOUNDS` / `V_BOUNDS` in
  `bin/streams/grid4_common.py` (Delta phi2 -10..23 deg; PMs and v_los unchanged);
- data: stream-54 members and frame `results/plot_data/stream54_gc_frame_chord.json`, along-stream window = member range.

## Inputs that changed independently of the score

- **Cluster reference state** (`9601ba7`, 2026-10-16 07:29): one source for omega Cen's position, PMs, distance and v_los
  (v_los 232.78 -> 232.7 km/s, PMs at 1e-4). Sprays made before and after differ at the ~10-20 ln L level, below the seed
  scatter. The refined bar fits (2026-10-13) predate it; the paper models (2026-10-16) were re-sprayed after it.
- **Spray speed-ups** (`dfc3d78`, 2026-10-11): trailing arm only and the 700 Myr cut; bit-identical output (tests).
- **Chunked orbit integration** (2026-10-17): memory only; bit-identical output (test).
- **Particle number and seeds**: in the results index (from the code) and, partly, in each results file. Totals depend on
  them (shot-noise bias of ln of a KDE, which grows as the particle number falls); compare models only at equal particle number.

## Known inconsistencies (audit 2026-10-17)

- Scripts that call `score_conditional` directly (`grid4.py`, `kernel_check.py`, `d2_mock_recovery.py`, `rescore_conditional.py`,
  `knee_spread_and_frame.py`, `fit_bar_ocen.py --conditional`) always compute S2, whatever the wrapper default.
- `obs_split.single_scores` (per-observable scores in `d1_segments.py`, `mass_sweep.py`, `cluster_mass_test.py`,
  `frame_obs_split.py`) and the plotting re-implementations (`plot_conditional_model.py`, `plot_conditional_orig.py`) hard-code
  S2. Next to a wrapper score from S3 onwards, the two columns use different definitions.
- Resumable or appending outputs skip entries already present (`paper_models.json`, `phase2_variants.json`, `phase2b_grid.json`,
  `profile_stage1.json`, `sun_dist_bar_grids.json`, `frame_decomp_edges.json`, `mass_sweep.json`, `cluster_mass_test.json`,
  `bar3d_sweep/`, `lmc_spray_test.jsonl`, the refinement / spiral / escape pilot files, the convergence and n_eff studies).
  Resumed after a version change, they would hold mixed versions with no marker in the file.
- `d1_segments.py` runs at import; `knee_spread_and_frame.py` imports it and so rewrites the D1 outputs.
