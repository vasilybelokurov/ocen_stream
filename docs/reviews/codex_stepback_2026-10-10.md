## 2. Is the explanation space exhausted?

No. A useful first gate is still missing: the existing backtrack compares observed stars with omega Cen’s orbit in **static** McMillan17 and DB98 hosts, over distances 2.5–6.5 kpc and 1.5 Gyr. Its scalar metric is a fixed weighted distance in position and velocity; it does not propagate measurement or cluster-state uncertainty. [bin/streams/backtrack_fimbulthul.py:15–16, 34–47](bin/streams/backtrack_fimbulthul.py#L15)

The rotating-bar machinery exists, including bar speed, present angle, slowing rate, amplitude, and size. That makes the proposed barred backtrack feasible, but the current star-backtrack script does not use it. [src/ocen_dm/streams/restricted.py:40–58, 60–89](src/ocen_dm/streams/restricted.py#L40)

Still genuinely open are:

- Whether knee stars can reach a **recent release region** in a plausible barred potential once astrometric, RV, distance, and omega Cen state uncertainties are propagated. The current backtrack uses point estimates for the listed observables and a distance grid, and fixes the cluster phase-space point. [bin/streams/backtrack_fimbulthul.py:26–47](bin/streams/backtrack_fimbulthul.py#L26)
- Debris older than the tested window, alternative progenitor structure or ancestry, and live self-gravity (the last is excluded by the PI’s constraint). [docs/STREAM_DIAGNOSTIC_PLAN.md:47–49](docs/STREAM_DIAGNOSTIC_PLAN.md#L47) [docs/STREAM_KNEE_INVESTIGATION.md:121–124, 134–138](docs/STREAM_KNEE_INVESTIGATION.md#L121)
- LMC reflex, broader time-dependent bar histories, and potential families beyond the sampled variants. [docs/STREAM_DIAGNOSTIC_PLAN.md:45–49](docs/STREAM_DIAGNOSTIC_PLAN.md#L45)
- The interpretation of the PM ridge beyond phi1≈24, where the independent selection did not recover a clear detection. [packet:2789–2794](.ask-codex-packet.XXXXXX.md#L2789)

## 3. Is the barred-backtrack “kill test” right?

Yes, as a **gate before further tuning**, but it needs a better target than “closest to the cluster’s orbit.” The existing test compares star and cluster trajectories using \(dx/0.2\) kpc and \(dv/20\) km/s, then takes the minimum over time and scanned distance. That is a useful diagnostic, but the scales are chosen constants, not propagated uncertainties or a release model. [bin/streams/backtrack_fimbulthul.py:2–5, 43–47](bin/streams/backtrack_fimbulthul.py#L2)

For the bar run, sample each star’s position, PMs, parallax or distance constraint, and RV uncertainty; sample omega Cen’s present state and the allowed host/bar parameters with their relevant constraints. Integrate both trajectories in the same time-dependent potential, with the present bar phase tied to its allowed angle range. Then measure whether the star’s uncertainty region intersects the **modeled escape/release distribution**—including finite tidal radius and escape velocity—not whether the star and cluster must occupy identical phase space. The bar implementation supports time-dependent rotation and slowing histories. [src/ocen_dm/streams/restricted.py:40–58, 60–89](src/ocen_dm/streams/restricted.py#L40)

I would abandon **recent omega Cen debris in the tested barred, test-particle framework** if the knee-star posterior repeatedly misses every plausible recent release distribution over the model’s relevant release ages, while the same method recovers the near-cluster arm and injected mock debris. That would reject the framework’s recent-release explanation; it would not prove that the stars never came from omega Cen, since older debris, self-gravity, or a different history remain outside that test.

## 4. Ranked plan

1. **Run the barred reachability test first.** Predefine the allowed bar and cluster-state ranges, release-age range, and overlap statistic; calibrate the threshold on near-cluster members and mock releases. **Stop tuning** if the knee stars remain incompatible across those ranges and mocks pass. **Continue** if a substantial knee subset overlaps plausible release regions.

2. **Resolve the observational edge and ancestry only if step 1 passes or is ambiguous.** Extend an independent Gaia/RV/chemistry check through the distal knee; the current independent PM detection stops short of its steepest part. **Go** if the same coherent PM track and compatible velocities persist; otherwise describe the distal feature’s membership as unresolved. [packet:2789–2794](.ask-codex-packet.XXXXXX.md#L2789)

3. **Only then profile the allowed barred model jointly**, with multiple seeds and mocks, including the remaining plausible host, bar-history, and omega Cen state variations. **Stop** if no fit reproduces the knee within the stated angle/state constraints; write up a negative result: the tested recent test-particle framework can make a partial bend but cannot match the observed PM track. The record already reports the persistent pmdec residual and cautions that the fit ranking is noisy or overconfident. [docs/STREAM_DIAGNOSTIC_PLAN.md:10–21, 63–69](docs/STREAM_DIAGNOSTIC_PLAN.md#L10)

**Assumptions:** I take the recorded numerical results and run summaries as accurate; I did not recompute the integrations or inspect every run artifact. “Plausible barred host” needs explicit parameter bounds agreed with the project’s priors.

**Strongest argument against my recommendation:** A successful orbit-connection test is not required to be a close pointwise match to the cluster orbit: real escapers leave with offsets, and the record itself notes that Ibata’s explanation invokes self-gravity of earlier debris. Conversely, a failed test can falsely reject ancestry if the distance/RV posterior, old release ages, or allowed bar history is too restrictive. The proposed test is therefore decisive only for the specified recent test-particle model, not for omega Cen ancestry in general.
