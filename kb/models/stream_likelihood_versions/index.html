    Stream likelihood versions¶

    Every stream ln L quoted in the journal, the plots or the paper was computed with one of the score versions below. Numbers from different versions are not comparable. The stream results index assigns each saved result file to a version, the script that wrote it, its non-default score options, its spray settings (particle number, seeds, frame, host options) and the code commit (generated by bin/streams/score_provenance.py from bin/streams/score_registry.py, a code audit of all 51 scripts that call a stream score, 2026-10-17).

    From 2026-10-17 every call to grid4_common.score() returns settings (version tag, explicit options, code commit, -dirty if the score code had uncommitted changes); scripts that save scores should store it with their results.

    Status (2026-10-17)

    • Chosen: fixed chi bins. The user chose fixed chi bins (equal weight per chi interval; candidate range 0-200 in steps of 5, i.e. chi_edges=np.arange(0., 205., 5.)) over the pooled KDE, because the density along the stream is not modelled reliably. Pooling weights each part of the stream by its debris fraction and so reintroduces that dependence (Codex review of the score provenance).
    • Default not yet changed. grid4_common.score() still defaults to pooled=True (S4-pooled) until the chi range is fixed.
    • Bias correction is not a score version. The jackknife correction of the particle-number bias (src/ocen_dm/streams/score_bias.py, commits 87771f5 and e6c4dc8) is applied to the scores after scoring.
    • Overall stream status: stream status.

    Settings common to S2-S4¶

    Fixed since 29d04f8 (checked against the function signature at every later commit that touched the score):

    • kernels: h_u = h_x = 0.5 deg (along / across the stream in the chord great-circle frame), PMs 0.2 mas/yr added to each member's Gaia covariance, v_los 5 km/s added to the measurement error;
    • background fraction eps = 0.05; release-age cut 700 Myr; trailing-arm particles with chi > 0;
    • chi bins (S2, S3 only): width 5, minimum 20 particles, each kept bin weight 1/K;
    • background: S2 widths 12 deg (Delta phi2) x 30 x 30 mas/yr x 400 km/s; S3 onwards the box BG_BOUNDS / V_BOUNDS in bin/streams/grid4_common.py (Delta phi2 -10..23 deg; PMs and v_los unchanged);
    • data: stream-54 members and frame results/plot_data/stream54_gc_frame_chord.json, along-stream window = member range.

    Inputs that changed independently of the score¶

    • Cluster reference state (9601ba7, 2026-10-16 07:29): one source for omega Cen's position, PMs, distance and v_los (v_los 232.78 -> 232.7 km/s, PMs at 1e-4). Sprays made before and after differ at the ~10-20 ln L level, below the seed scatter. The refined bar fits (2026-10-13) predate it; the paper models (2026-10-16) were re-sprayed after it.
    • Spray speed-ups (dfc3d78, 2026-10-11): trailing arm only and the 700 Myr cut; bit-identical output (tests).
    • Chunked orbit integration (2026-10-17): memory only; bit-identical output (test).
    • Particle number and seeds: in the results index (from the code) and, partly, in each results file. Totals depend on them (shot-noise bias of ln of a KDE, which grows as the particle number falls); compare models only at equal particle number.

    Known inconsistencies (audit 2026-10-17)¶

    • Scripts that call score_conditional directly (grid4.py, kernel_check.py, d2_mock_recovery.py, rescore_conditional.py, knee_spread_and_frame.py, fit_bar_ocen.py --conditional) always compute S2, whatever the wrapper default.
    • obs_split.single_scores (per-observable scores in d1_segments.py, mass_sweep.py, cluster_mass_test.py, frame_obs_split.py) and the plotting re-implementations (plot_conditional_model.py, plot_conditional_orig.py) hard-code S2. Next to a wrapper score from S3 onwards, the two columns use different definitions.
    • Resumable or appending outputs skip entries already present (paper_models.json, phase2_variants.json, phase2b_grid.json, profile_stage1.json, sun_dist_bar_grids.json, frame_decomp_edges.json, mass_sweep.json, cluster_mass_test.json, bar3d_sweep/, lmc_spray_test.jsonl, the refinement / spiral / escape pilot files, the convergence and n_eff studies). Resumed after a version change, they would hold mixed versions with no marker in the file.
    • d1_segments.py runs at import; knee_spread_and_frame.py imports it and so rewrites the D1 outputs.
