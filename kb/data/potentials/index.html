    Potentials and auxiliary inputs¶

    P1. Hunter+2024 MW potentials. - Location. OB/agama_potentials/MWPotentialHunter24_*.ini, from the oCen_bar clone (github.com/adllmr/oCen_bar per the project journal). - Path convention. Hunter et al. 2024, A&A 692, A216, arXiv:2403.18000: 2024A&A...692A.216H (docs/kb/literature.json).

    P2. Portail17.ini and Portail17_axi.ini (241,764 B and 47,001 B). - Used through opt-in bar_model='portail17' (restricted.py:72,98). - Paper: Portail+2017, arXiv:1608.07954 (project journal). The provenance of the .ini files is UNVERIFIED.

    P3. MWPotential2014_mod.ini (469 B). - Used by tails/bar_migration.py:155. Source UNVERIFIED.

    P5. DB98_Model1.ini. - File: configs/potentials/DB98_Model1.ini (1,284 B).     Frames and host variants (stream models)¶

    These are fixed inputs of every stream spray, set in code rather than read from data files.

    • Solar frames (src/ocen_dm/streams/frames.py, FRAMES):
    Frame R0 (kpc) z⊙ (pc) V⊙ (km/s) ω Cen distance (kpc)
    baumgardt (default) 8.178 0 (11.1, 252.24, 7.25) 5.43 (cluster.OCEN_DISTANCE_KPC)
    ibata19 (Ibata+2019 host) 8.122 17 (11.1, 232.24, 7.25) 5.63

    V⊙ is astropy's galcen_v_sun. The model (AGAMA) frame flips the sign of x and vx relative to astropy's Galactocentric frame. - Cluster reference state (src/ocen_dm/cluster.py, since 2026-10-16): centre (201.69683333, −47.47956944) deg; systemic PM (−3.250, −6.746) ± 0.022 mas/yr; vlos 232.7 ± 0.2 km/s; distance 5.43 ± 0.05 kpc. Sources are on the cluster data page (L3). Runs before 2026-10-16 started from the Baumgardt orbit-table state, which differs by 0.04″ in position, 10⁻⁴ mas/yr in PM and 0.08 km/s in vlos (frames.py docstring). - Axisymmetric host variants (src/ocen_dm/streams/mw_variants.py, axisymmetric_variant). The Hunter+2024 axisymmetric baryons (MWPotentialHunter24_baryon_axi.ini) plus its dark halo, with: - halo flattening q (halo_q, axisRatioZ); - disc scale (disc_scale), which adds (scale − 1) × the thin and thick stellar discs; - vc(R0 = 8.178 kpc) set through the halo normalisation: kept at the original model's value by default, or set to vc_target.

    The bar's non-axisymmetric part, A × (baryon_full − baryon_axi), is added unchanged. - LMC (src/ocen_dm/streams/lmc.py). Rigid MW and rigid LMC on their mutual orbit, following Vasiliev, Belokurov & Erkal 2021 (Sect. 3.1), without halo deformation. Particles are integrated in the MW-centred frame with the reflex acceleration, so only the tidal LMC field acts. The LMC is a truncated NFW with rs = 8.5 (M/10¹¹ M⊙)0.6 kpc, cut off at 10 rs; default mass 1.5×10¹¹ M⊙ (with_lmc). Dynamical friction acts on the LMC only. Present-day LMC: ICRS (81.0, −69.75) deg, PM (1.8, 0.35) mas/yr, d = 50 kpc, vlos = 260 km/s. - Bar size limit (bin/streams/training_set.py). Size S scales the Hunter+2024 bar; at S = 1 its length is Rbar = 4.25 kpc (the A2 half-peak length; RBAR_KPC). In the emulator design S runs from 0.8 to min(1.5, RCR/4.25 kpc), so the bar never extends beyond corotation RCR of that point's axisymmetric host. - Stream background box. The uniform background of the stream likelihood is normalised over an explicit box (Δφ2 −10 to 23 deg) since score S3; see stream likelihood versions.
